# E2-S2: Login API endpoint

**Epic:** E2 — Authentication
**Layer:** API
**Group:** D
**Depends on:** E2-S1

## Description

Expose a POST endpoint that accepts email/password and returns the JWT and role, forming the single entry point for all four personas.

## Acceptance Criteria

1. POST /api/auth/login with a valid seeded email/password returns 200 with a JSON body containing access_token and role.
2. POST /api/auth/login with an invalid password returns 401 with no token in the response body.
3. POST /api/auth/login with a malformed request body (missing email or password) returns 422.
4. The response body never includes password_hash or any other credential material.
5. All subsequent protected endpoints reject requests missing a valid Authorization: Bearer header with 401.
