# E8-S2: Rebalancing engine service

**Epic:** E8 — Rebalancing
**Layer:** Service
**Group:** E
**Depends on:** E6-S3, E8-S1, E3-S2

## Description

Detect per-asset-class drift exceeding the configured threshold and propose BUY/SELL quantities, gated by kyc_verified, per AC-06 and the BRD's kyc gating rule.

## Acceptance Criteria

1. For a customer whose holdings drift exceeds the configured threshold on at least one asset class, the service creates a RebalancingRecommendation with proposed_actions_json containing BUY/SELL quantities that move the customer's allocation toward target.
2. For a customer whose drift is within threshold on every asset class, the service creates no recommendation (no-op).
3. For a customer with zero holdings, the service is a documented no-op, not an error, per the BRD edge-case table.
4. For a customer with kyc_verified = false, the service produces no RebalancingRecommendation even if drift exceeds threshold, enforcing the BRD's one real gating branch for the stub flag.
5. A successful recommendation creation invokes the audit-writer service exactly once with entity_type=RebalancingRecommendation.
6. All proposed BUY/SELL quantities are computed using fixed-point arithmetic, never floating-point.
