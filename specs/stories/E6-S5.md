# E6-S5: Holdings and drift UI view

**Epic:** E6 — Asset Price Feed, Holdings & Drift
**Layer:** UI
**Group:** F
**Depends on:** E6-S4, E2-S3

## Description

Display current holdings and per-asset-class drift to the customer, per BRD section 12.

## Acceptance Criteria

1. The view lists each held asset class with its current value, current percent, target percent, and drift percent.
2. An asset class whose drift exceeds the configured threshold is visually distinguished from those within tolerance.
3. A customer with zero holdings sees an explicit empty-state message rather than a blank or broken table.
4. All numeric values are rendered with a fixed number of decimal places consistent with the backend's fixed-point representation.
5. The view is reachable via a persistent navigation link from the customer dashboard.
