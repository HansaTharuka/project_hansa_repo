# E10-S2: Admin publish service

**Epic:** E10 — Admin Console
**Layer:** Service
**Group:** E
**Depends on:** E10-S1, E3-S2

## Description

Implement server-side validation for publishing rule/template versions, including live sum-to-100 checks and 409 handling on version races, plus asset-class CRUD, per AC-10.

## Acceptance Criteria

1. Publishing an AllocationTemplate whose allocations_json percentages do not sum to exactly 100 is rejected with a validation error and no row is written, per the BRD edge-case table.
2. Publishing a RiskBandRule with fewer than 6 questions in questionnaire_json is rejected with a validation error.
3. Two concurrent publish calls for the same risk_band's next version are serialized such that exactly one succeeds and the other raises a conflict error mapped to 409 at the API layer.
4. A successful publish invokes the audit-writer service exactly once with entity_type reflecting the rule or template published.
5. Asset-class create/update validates that code is unique before insert.
