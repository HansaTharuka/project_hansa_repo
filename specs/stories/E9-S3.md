# E9-S3: Advisor API (customer list, drill-in, override, manual-rec log)

**Epic:** E9 — Advisor Workflows
**Layer:** API
**Group:** G
**Depends on:** E9-S2, E2-S2

## Description

Expose advisor-role endpoints to list customers, view a customer's portfolio, submit an override, and log a manual recommendation.

## Acceptance Criteria

1. GET /api/advisor/customers with an advisor-role JWT returns 200 with a list of customers including their current risk band.
2. GET /api/advisor/customers/{id} returns that customer's portfolio detail (holdings, goals, current allocation) for drill-in.
3. POST /api/advisor/customers/{id}/override with a valid reason returns 201 and the new risk_band; the same call without reason returns 422.
4. POST /api/advisor/customers/{id}/manual-recommendation logs the recommendation and returns 201.
5. Any of the above endpoints called with a customer- or compliance-role JWT returns 403.
