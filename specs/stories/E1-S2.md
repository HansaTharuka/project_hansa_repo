# E1-S2: Application configuration and environment settings

**Epic:** E1 — Platform Foundation
**Layer:** Config
**Group:** A
**Depends on:** None (Group A — no dependencies)

## Description

Centralize environment-driven configuration (DB connection string, JWT secret/expiry, default rebalancing drift threshold, seed CSV path) into a single config module so no service hardcodes environment-specific values.

## Acceptance Criteria

1. A backend config module exposes typed settings including database_url, jwt_secret, jwt_access_token_expiry_minutes, default_drift_threshold_percent (default value 5), and seed_csv_path, loaded from environment variables with documented defaults.
2. Missing a required environment variable at startup raises a clear startup error rather than the app silently starting with None values.
3. The drift threshold is exposed as a versionable config value, not a literal hardcoded inside the rebalancing service, matching BRD section 5.1's default-5%-versioned requirement.
4. No secret value (JWT secret, DB credentials) appears hardcoded in source outside the config module; the repo's detect-secrets hook passes on the config module.
5. A .env.example file documents every required environment variable with a placeholder value.
