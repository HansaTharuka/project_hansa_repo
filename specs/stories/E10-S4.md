# E10-S4: Admin UI (rule editor, template editor, asset-class master)

**Epic:** E10 — Admin Console
**Layer:** UI
**Group:** G
**Depends on:** E10-S3, E2-S3

## Description

Build the admin console screens per BRD section 12: risk-band rule editor, allocation template editor with live sum-to-100 validation, and asset-class master management.

## Acceptance Criteria

1. The allocation template editor shows a running total of entered percentages and visually flags, before submit, when the total is not exactly 100.
2. The Publish button on the template editor is disabled while the running total is not exactly 100.
3. The risk-band rule editor allows adding/removing questions and requires at least 6 before enabling publish.
4. The asset-class master screen lists all asset classes and supports adding a new one; submitting a duplicate code shows an inline error sourced from the API's 409 response.
5. Publishing a new template/rule version from the UI refreshes the displayed version history without a full page reload.
