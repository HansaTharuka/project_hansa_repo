# E8-S4: Rebalancing recommendations UI

**Epic:** E8 — Rebalancing
**Layer:** UI
**Group:** G
**Depends on:** E8-S3, E2-S3

## Description

Display pending rebalancing recommendations with accept/dismiss actions, per BRD section 12.

## Acceptance Criteria

1. The screen lists every pending recommendation with its proposed BUY/SELL actions per asset class.
2. Clicking Accept calls the accept API and removes the recommendation from the pending list on success.
3. Clicking Dismiss calls the dismiss API and removes the recommendation from the pending list on success.
4. A customer with no pending recommendations sees an explicit empty-state message.
5. Both action buttons are keyboard-operable and disabled while their respective API call is in flight, preventing double-submit.
