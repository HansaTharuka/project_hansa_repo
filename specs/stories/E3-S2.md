# E3-S2: Central audit-writer service

**Epic:** E3 — Audit Trail
**Layer:** Service
**Group:** D
**Depends on:** E3-S1

## Description

Provide a single reusable service function that every domain service (risk profiling, recommendation, rebalancing, advisor override, admin publish) calls to record an audit entry, so audit logging is consistent and cannot be bypassed.

## Acceptance Criteria

1. Calling the audit-writer with a valid entity_type, entity_id, actor_id, actor_role, action, and details dict produces exactly one new row in the audit repository.
2. The audit-writer rejects a call missing actor_role or with an actor_role outside {customer, advisor, admin, compliance}.
3. A unit test verifies at least one downstream domain flow (risk-band assignment) invokes the audit-writer exactly once per assignment.
4. The audit-writer never silently overwrites a prior entry with the same entity_id; each call always inserts a new row.
5. Failures inside the audit-writer propagate as an exception rather than being silently swallowed, so a caller cannot commit a business action while losing its audit trail.
