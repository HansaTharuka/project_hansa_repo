# E7-S5: Goals UI (list, create/edit, progress)

**Epic:** E7 — Goals & Progress Tracking
**Layer:** UI
**Group:** G
**Depends on:** E7-S4, E2-S3

## Description

Build the customer goals screen per BRD section 12: list, create/edit form, and progress display.

## Acceptance Criteria

1. The goals list screen displays every goal for the logged-in customer with target_amount, target_date, priority, and current percent_complete.
2. Submitting the create-goal form with a negative or zero target_amount shows an inline validation error and does not call the create API.
3. Each goal's progress is rendered as a progress bar or percentage label reflecting the latest GoalProgressSnapshot.
4. Editing an existing goal's priority via the form updates the displayed value after save without a full page reload.
5. All form inputs are labeled and keyboard-operable.
