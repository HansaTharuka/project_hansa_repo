# E5-S3: Recommendation API endpoint

**Epic:** E5 — Allocation Recommendation
**Layer:** API
**Group:** G
**Depends on:** E5-S2, E2-S2

## Description

Expose the endpoint for a customer to fetch their current recommended allocation.

## Acceptance Criteria

1. GET /api/recommendation for an authenticated customer with an existing risk-band assignment returns 200 with an allocation breakdown whose percentages sum to 100.
2. The same endpoint for a customer with no risk-band assignment yet returns 404 rather than a default allocation.
3. The endpoint called with an advisor- or admin-role JWT returns 403.
4. The response includes the version of the AllocationTemplate used, enabling traceability to AC-10's immutability guarantee.
5. An unauthenticated request returns 401.
