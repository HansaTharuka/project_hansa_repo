# E6-S3: Holdings and per-asset-class drift calculation service

**Epic:** E6 — Asset Price Feed, Holdings & Drift
**Layer:** Service
**Group:** D
**Depends on:** E6-S1

## Description

Compute each customer's current per-asset-class holding value against their target allocation and derive drift percentage, using fixed-point arithmetic per NFR-01.

## Acceptance Criteria

1. Given a customer's holdings and their active recommended allocation, the service returns, for each asset class, current_percent, target_percent, and drift_percent = current_percent - target_percent.
2. All drift calculations use fixed-point/decimal arithmetic; a unit test confirms no float type appears in any intermediate or final drift value.
3. A customer with zero holdings produces an empty drift result, not an error and not a divide-by-zero exception.
4. Drift values at exact boundary conditions (drift exactly equal to the configured threshold) are handled per a documented rounding rule where the threshold is exclusive: drift must exceed, not equal, the threshold to trigger rebalancing.
5. The sum of a customer's current_percent values across all held asset classes equals 100, within a documented fixed-point rounding tolerance, when the customer holds at least one asset.
