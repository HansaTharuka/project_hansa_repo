# E3-S4: Compliance audit-log UI screen

**Epic:** E3 — Audit Trail
**Layer:** UI
**Group:** F
**Depends on:** E3-S3, E2-S3

## Description

Build the dedicated, read-only audit-log screen for the Compliance/Auditor persona described in BRD section 12, filterable by actor, entity type, and date range.

## Acceptance Criteria

1. Logging in as the seeded compliance user lands on the audit-log screen showing a table of audit entries with columns for actor, entity type, action, and timestamp.
2. Selecting an entity-type filter and applying it re-queries the API and displays only entries matching that entity type.
3. Selecting a date range filter and applying it displays only entries with timestamp within the selected range (inclusive).
4. No UI control on this screen allows editing or deleting an audit entry; the screen contains zero action buttons other than filter/apply/clear.
5. All filter inputs are labeled and keyboard-operable (tab-focusable, submit via Enter key).
