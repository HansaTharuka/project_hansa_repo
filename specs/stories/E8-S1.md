# E8-S1: RebalancingRecommendation repository

**Epic:** E8 — Rebalancing
**Layer:** Repository
**Group:** C
**Depends on:** E1-S3

## Description

Persist rebalancing recommendations with an append-only status lifecycle (pending -> accepted/dismissed), per AC-06/AC-07 and NFR-02.

## Acceptance Criteria

1. The repository inserts a RebalancingRecommendation row with status = pending, proposed_actions_json, and generated_at.
2. Transitioning status to accepted or dismissed sets resolved_at and never deletes the original row.
3. A repository test confirms no method exists to hard-delete a RebalancingRecommendation row.
4. status only ever transitions from pending to exactly one terminal state (accepted or dismissed); a second transition attempt on an already-resolved recommendation is rejected.
5. get_pending(customer_id) returns only rows with status = pending for that customer.
