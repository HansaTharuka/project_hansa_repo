# E5-S4: Recommended allocation UI view

**Epic:** E5 — Allocation Recommendation
**Layer:** UI
**Group:** H
**Depends on:** E5-S3, E2-S3

## Description

Display the customer's recommended allocation, per BRD section 12.

## Acceptance Criteria

1. The allocation view renders each asset class with its recommended percentage, and the displayed percentages sum to 100 as shown on screen.
2. If the customer has no risk-band assignment, the view prompts them to complete the risk-profile questionnaire instead of showing an empty/broken chart.
3. The view is reachable via a persistent navigation link from the customer dashboard.
4. Percentage values are rendered with a consistent, fixed number of decimal places, with no floating-point rounding artifacts.
5. The view refetches and re-renders if the customer's risk band changes (e.g., after an advisor override) without requiring a full page reload.
