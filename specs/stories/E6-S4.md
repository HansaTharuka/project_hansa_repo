# E6-S4: Holdings/drift and advance-day admin API

**Epic:** E6 — Asset Price Feed, Holdings & Drift
**Layer:** API
**Group:** E
**Depends on:** E6-S2, E6-S3, E2-S2

## Description

Expose customer-facing holdings/drift read endpoints and an admin-only advance-a-day trigger endpoint.

## Acceptance Criteria

1. GET /api/holdings for an authenticated customer returns 200 with their current holdings and drift per asset class.
2. POST /api/admin/advance-day with an admin-role JWT returns 200 and the new simulated price_date.
3. POST /api/admin/advance-day with a customer- or advisor-role JWT returns 403.
4. Calling POST /api/admin/advance-day twice in immediate succession returns 200 the first time and either a 200 no-op response or a 409 the second time, never silently duplicating NAV data.
5. GET /api/holdings for a customer with no holdings returns 200 with an empty list, not an error.
