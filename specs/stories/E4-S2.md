# E4-S2: Deterministic risk-band scoring service

**Epic:** E4 — Risk Profiling
**Layer:** Service
**Group:** E
**Depends on:** E4-S1, E3-S2

## Description

Implement the scoring engine that maps a completed set of questionnaire answers to a deterministic risk band (CONSERVATIVE, MODERATE, or AGGRESSIVE) using the active RiskBandRule version, and records the assignment via the audit-writer.

## Acceptance Criteria

1. Given the same complete set of answers submitted twice, the service returns the identical risk band both times (deterministic, no randomness).
2. Given an incomplete answer set (fewer than the questionnaire's required question count), the service raises a validation error rather than producing a partial risk-band assignment, per the BRD edge-case table.
3. A successful scoring call creates a RiskBandAssignment row recording customer_id, risk_band, rule_version (the RiskBandRule version used), and assigned_at.
4. A successful scoring call invokes the audit-writer service exactly once with entity_type=RiskBandAssignment.
5. Scoring uses only fixed-point/integer arithmetic for point totals and thresholds; no floating-point comparison, per NFR-01.
6. RiskBandAssignment rows are never updated in place; a re-submission creates a new row rather than mutating the prior assignment, preserving append-only history (NFR-02).
