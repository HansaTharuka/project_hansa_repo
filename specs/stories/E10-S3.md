# E10-S3: Admin API (publish rule/template version, asset-class CRUD)

**Epic:** E10 — Admin Console
**Layer:** API
**Group:** F
**Depends on:** E10-S2, E2-S2

## Description

Expose admin-role endpoints for publishing new rule/template versions and managing the asset-class master.

## Acceptance Criteria

1. POST /api/admin/risk-band-rules with a valid questionnaire (>=6 questions) and scoring rules returns 201 with the new version number.
2. POST /api/admin/allocation-templates with percentages summing to 100 returns 201; the same call with percentages summing to 99 or 101 returns 422.
3. POST /api/admin/asset-classes with a duplicate code returns 409.
4. All three endpoints called with a customer-, advisor-, or compliance-role JWT return 403.
5. GET /api/admin/allocation-templates?risk_band=CONSERVATIVE returns all versions (active and superseded) for that risk band, ordered by version.

## Traceability

Feature IDs: F198, F199, F200, F201, F202
