# E7-S4: Goals API (CRUD and progress)

**Epic:** E7 — Goals & Progress Tracking
**Layer:** API
**Group:** F
**Depends on:** E7-S2, E7-S3, E2-S2

## Description

Expose endpoints for a customer to create, edit, list goals, and view progress history.

## Acceptance Criteria

1. POST /api/goals with valid target_amount, target_date, and priority returns 201 with the created goal's id.
2. POST /api/goals with target_amount <= 0 returns 422.
3. GET /api/goals for the authenticated customer returns only that customer's goals, never another customer's.
4. GET /api/goals/{id}/progress returns the ordered history of GoalProgressSnapshot rows for that goal.
5. PATCH /api/goals/{id} updating priority returns 200 with the updated value reflected in a subsequent GET.
