# E8-S3: Rebalancing API (list, accept, dismiss)

**Epic:** E8 — Rebalancing
**Layer:** API
**Group:** F
**Depends on:** E8-S2, E2-S2

## Description

Expose endpoints for a customer to view and act on their pending rebalancing recommendations.

## Acceptance Criteria

1. GET /api/rebalancing for the authenticated customer returns their pending recommendations.
2. POST /api/rebalancing/{id}/accept transitions the recommendation's status to accepted, returns 200, and creates an audit entry.
3. POST /api/rebalancing/{id}/dismiss transitions the recommendation's status to dismissed, returns 200, and creates an audit entry.
4. Calling accept or dismiss on an already-resolved recommendation returns 409 and does not change its resolved_at.
5. A customer cannot accept/dismiss another customer's recommendation; the endpoint returns 403 or 404 for a mismatched customer_id.
