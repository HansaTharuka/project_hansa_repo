# E5-S2: Allocation recommendation service

**Epic:** E5 — Allocation Recommendation
**Layer:** Service
**Group:** F
**Depends on:** E5-S1, E4-S2, E3-S2

## Description

Combine a customer's current risk band with their goal horizon to select and return the correct active allocation template, recording an audit entry.

## Acceptance Criteria

1. Given a customer with a CONSERVATIVE risk band, the service returns the active AllocationTemplate for CONSERVATIVE whose percentages sum to exactly 100.
2. Given a customer with no RiskBandAssignment yet, the service raises an error rather than returning a default/fallback allocation.
3. A successful recommendation call invokes the audit-writer service exactly once with entity_type reflecting the recommendation event.
4. The service's goal-horizon-based selection logic is deterministic: the same risk band and horizon input always yields the same template selection.
5. The returned allocation percentages are represented as fixed-point/decimal values summing to exactly 100, never floating-point (NFR-01).
