# E3-S3: Audit log API (filterable, compliance-role-only)

**Epic:** E3 — Audit Trail
**Layer:** API
**Group:** E
**Depends on:** E3-S2, E2-S2

## Description

Expose a read-only, role-gated endpoint for compliance/auditor users to query the audit trail filtered by actor, entity type, and date range.

## Acceptance Criteria

1. GET /api/audit?actor_id=...&entity_type=...&from=...&to=... with a compliance-role JWT returns 200 with a paginated list of matching audit entries.
2. The same endpoint called with a customer-, advisor-, or admin-role JWT returns 403.
3. No POST, PUT, PATCH, or DELETE method is registered on the /api/audit route; attempting any of them returns 405.
4. Filtering by entity_type=RiskBandAssignment returns only rows whose entity_type matches exactly, excluding all other entity types.
5. An unauthenticated request (no Bearer token) returns 401.
