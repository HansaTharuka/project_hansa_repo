# E6-S1: AssetClass and NavSnapshot repository plus seed CSV loader

**Epic:** E6 — Asset Price Feed, Holdings & Drift
**Layer:** Repository
**Group:** C
**Depends on:** E1-S3

## Description

Load the initial asset-class master and NAV price history from a seed CSV at startup, and persist subsequent NAV snapshots.

## Acceptance Criteria

1. On first startup against an empty database, the seed CSV loader inserts 5-6 AssetClass rows and one NavSnapshot row per asset class for the initial price_date.
2. Re-running the loader against an already-seeded database does not create duplicate AssetClass rows (unique constraint on code).
3. NavSnapshot rows are append-only; the repository exposes no update method for existing snapshots.
4. get_latest_nav(asset_class_id) returns the NavSnapshot with the most recent price_date for that asset class.
5. nav_value is stored as a fixed-point/decimal type, never floating-point.
