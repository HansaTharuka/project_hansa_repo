# E7-S1: Goal and GoalProgressSnapshot repository

**Epic:** E7 — Goals & Progress Tracking
**Layer:** Repository
**Group:** C
**Depends on:** E1-S3

## Description

Persist customer financial goals and append-only progress snapshots recomputed on each NAV refresh, per AC-03 and AC-08.

## Acceptance Criteria

1. The repository supports creating multiple Goal rows per customer_id, each with target_amount, target_date, priority, and created_at.
2. GoalProgressSnapshot rows are insert-only; the repository exposes no update/delete method for existing snapshots, per NFR-02.
3. get_latest_progress(goal_id) returns the GoalProgressSnapshot with the most recent snapshot_at for that goal.
4. target_amount is stored as a fixed-point/decimal type, never floating-point.
5. Editing a Goal's mutable fields (e.g., target_amount, priority) is supported via a documented update path distinct from the append-only GoalProgressSnapshot history.
