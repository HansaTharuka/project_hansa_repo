# E4-S3: Risk-profile submission API

**Epic:** E4 — Risk Profiling
**Layer:** API
**Group:** F
**Depends on:** E4-S2, E2-S2

## Description

Expose the endpoint through which an authenticated customer submits questionnaire answers and receives their assigned risk band.

## Acceptance Criteria

1. POST /api/risk-profile/submit with a complete, valid answer set and a customer-role JWT returns 201 with the assigned risk_band in the response body.
2. The same endpoint with an incomplete answer set returns 422 and creates no RiskBandAssignment row.
3. The endpoint called with an advisor- or admin-role JWT returns 403 (customer-only action).
4. GET /api/risk-profile/latest for the authenticated customer returns their most recent RiskBandAssignment, or 404 if none exists yet.
5. An unauthenticated request returns 401.
