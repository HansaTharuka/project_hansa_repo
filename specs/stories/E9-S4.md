# E9-S4: Advisor UI (customer list, drill-in, override form, manual-rec modal)

**Epic:** E9 — Advisor Workflows
**Layer:** UI
**Group:** H
**Depends on:** E9-S3, E2-S3

## Description

Build the advisor screens per BRD section 12: customer list, drill-in view, override form, and manual-recommendation modal on the drill-in view (not a standalone screen).

## Acceptance Criteria

1. The advisor customer list screen displays every customer with their current risk band and links to a drill-in view.
2. The drill-in view shows the customer's holdings, goals, and current allocation on a single screen.
3. Submitting the override form without entering a reason shows an inline validation error and does not call the override API.
4. Submitting a valid override updates the displayed risk band on the drill-in view without a full page reload.
5. The manual-recommendation log control is a modal/panel launched from the drill-in view, not a separate route/screen, matching BRD section 5.1's explicit constraint.
