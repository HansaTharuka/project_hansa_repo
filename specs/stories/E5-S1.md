# E5-S1: Versioned allocation-template repository

**Epic:** E5 — Allocation Recommendation
**Layer:** Repository
**Group:** C
**Depends on:** E1-S3

## Description

Persist per-risk-band allocation templates as immutable, versioned rows whose asset-class percentages always sum to 100, per AC-02 and AC-10.

## Acceptance Criteria

1. The repository rejects, at the data-access boundary, any insert attempt where the sum of allocations_json percentages for a template does not equal exactly 100.
2. AllocationTemplate rows are insert-only; no update method is exposed, publishing a correction requires inserting a new version.
3. get_active_template(risk_band) returns exactly one active, published template for a given risk band at any point in time.
4. Two published template versions for the same risk_band retain distinct version numbers, and both remain individually queryable by version after a newer one is published, supporting in-flight customer pinning.
5. Seeding creates 2 allocation-template versions per risk band (6 total across 3 bands), matching BRD section 9 seed volumes.
